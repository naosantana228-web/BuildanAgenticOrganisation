# Student-Authored Reflection — Do Not Generate With AI

The assignment brief explicitly requires this section to be written in the student's own words. Use the questions below only as a private planning scaffold, then write approximately 300 words independently from your own development notes and observed runs.

1. Which real pipeline behaviour worked more effectively than you expected? Refer to a concrete run or prompt revision.
2. Which handoff exposed an ambiguity, fabricated assumption, slow response, or usability weakness? What did you change after noticing it?
3. How did the live source influence the Researcher’s output, and what would have been weaker if you had used a static update?
4. Where did the five-agent division help, and where did it create extra cost, latency, complexity, or context loss?
5. Which user trust, GDPR, accessibility, and human-review concerns became clear while building the prototype?
6. What precise improvement would you make with another week: source ranking, human approval, model evaluation, retrieval quality, UI feedback, or deployment resilience?

Do not paste generated prose here. Retain your own dated notes, test observations, and screenshots to support an authentic reflection.
