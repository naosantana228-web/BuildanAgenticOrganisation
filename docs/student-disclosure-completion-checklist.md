# Student-Completed Disclosure Checklist

Complete these items yourself before submitting. They require your personal knowledge or direct review; do not copy a generic declaration that you cannot substantiate.

| Required completion | Where to record it | Your action |
|---|---|---|
| Student identity and module details | First page of the final report | Enter your own name, student number if required, module, and submission date. |
| Runtime model/version | `ai-use-ledger.md` and report disclosure | Read the model/version shown in your verified run or implementation environment and record it accurately. |
| Prompts and agent roles | AI-use ledger / report Agent Designs section | Confirm that the five full prompts match the deployed Agent Design page. |
| Human verification undertaken | AI-use ledger | List what you personally checked, such as the public URL, source evidence, run ID, report citations, and code archive. |
| Report factual accuracy | Final report | Check all dates, source claims, figure captions, and the public run ID against the evidence package. |
| Personal reflection | Final report | Write approximately 300 words in your own words using your genuine observations. Do not use generated reflection prose. |

> **Integrity boundary:** The reflection and first-person verification statements must be your own work. The factual evidence guides are there to help you check the record, not to substitute for your judgement or authorship.
